# LJT-Homepage

Personal academic homepage of Junteng Liu, built by forking the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Pages

- **About** (`_pages/about.md`, site root): biography, research interests and skills, academic background, research experience, publications, and contact information.
- **Publications** (`_pages/publications.html`): publication records rendered from the `_publications` collection.

## Configuration

Site and author settings live in `_config.yml`; header links are defined in `_data/navigation.yml`.

## Building

The site is built and deployed to GitHub Pages by the GitHub Actions workflow in `.github/workflows/jekyll.yml`. For local development, follow the [Academic Pages documentation](https://github.com/academicpages/academicpages.github.io#readme).
